# Matrice de dovezi

Comenzile se rulează din rădăcina repository-ului. Fiecare limită de afirmație restrânge dovada la comportamentul observabil în codul clientului.

| Capability | Verified evidence | Exact path/symbol | Verification command | Claim boundary |
| --- | --- | --- | --- | --- |
| Orchestrarea interfeței | Componenta principală gestionează dashboard-ul, filtrele, selecția, tab-urile și acțiunile locale. | [`src/App.tsx`](../src/App.tsx): `App`, `selectField`, `updateFilter`, `activeTab` | `rg -n 'function App|selectField|updateFilter|activeTab' src/App.tsx` | Dovedește orchestrarea în client, nu un workflow backend. |
| Alegerea sursei de date | Modul demo folosește workspace-ul local; API mode activează query-ul `loadParcels` și nu face fallback la fixtures pentru eroare sau răspuns gol. | [`src/App.tsx`](../src/App.tsx): `dataMode`, `readDemoWorkspace`, `useQuery`, `fields` | `rg -n 'dataMode|readDemoWorkspace|useQuery|apiFields' src/App.tsx` | API mode conectează la runtime numai citirea câmpurilor. |
| Calea Render `/parcels` | README declară `VITE_API_URL=https://farm-registry-api-demo.onrender.com`; Axios folosește `VITE_API_URL`, iar `loadParcels` face `GET /parcels`. | [`README.md`](../README.md): „Demo live”, „Mod API”; [`src/api.ts`](../src/api.ts): `client`, `loadParcels` | `rg -n 'farm-registry-api-demo.onrender.com|GET /parcels|VITE_API_URL' README.md src/api.ts` | Dovedește calea de citire configurată și codul client; nu dovedește disponibilitatea continuă a serviciului. |
| Limitele clientului API | Sunt definite citiri pentru ferme, câmpuri, sarcini și observații; `loadFields` păstrează compatibilitatea prin `loadParcels`. | [`src/api.ts`](../src/api.ts): `loadFarms`, `loadFields`, `loadTasks`, `loadObservations`, `loadParcels` | `rg -n 'function load(Farms|Fields|Tasks|Observations|Parcels)' src/api.ts` | Existența funcțiilor nu înseamnă că toate sunt apelate de `App`; runtime-ul curent folosește `loadParcels`. |
| Leaflet + OSM + GeoJSON | `MapView` compune `MapContainer`, `TileLayer` cu URL OpenStreetMap și stratul `GeoJSON`. | [`src/App.tsx`](../src/App.tsx): `MapView` | `rg -n 'MapContainer|TileLayer|tile.openstreetmap.org|<GeoJSON' src/App.tsx` | Dovedește configurația hărții în cod, nu proveniența sau exactitatea geometriilor. |
| Conversia geometriei | Câmpurile sunt transformate într-un GeoJSON `FeatureCollection`; un câmp poate fi transformat într-un `Feature` pentru export. | [`src/App.tsx`](../src/App.tsx): `toFeatureCollection`, `fieldToGeoJSON` | `rg -n 'toFeatureCollection|fieldToGeoJSON|FeatureCollection' src/App.tsx` | Conversia păstrează geometria furnizată; nu validează date GPS ori cadastrale. |
| Stare și persistență locală | `readDemoWorkspace` citește `localStorage`; efectul din `App` scrie numai când `mode === 'demo'`; `resetDemo` șterge cheia. | [`src/App.tsx`](../src/App.tsx): `LOCAL_KEY`, `readDemoWorkspace`, efectul de persistență, `resetDemo` | `rg -n 'LOCAL_KEY|localStorage|getItem|setItem|removeItem' src/App.tsx` | Persistența este locală browserului și numai pentru demo; nu este bază de date ori sincronizare între clienți. |
| Mutations și audit locale | Crearea/finalizarea sarcinilor și adăugarea/revizuirea observațiilor folosesc `setLocalWorkspace`; fiecare schimbare adaugă activitate prin `addAudit`. | [`src/App.tsx`](../src/App.tsx): `addAudit`, `createTask`, `completeTask`, `addObservation`, `reviewObservation` | `rg -n 'addAudit|createTask|completeTask|addObservation|reviewObservation|setLocalWorkspace' src/App.tsx` | Nu există apel backend de scriere în aceste fluxuri; în API mode schimbările sunt doar în memoria sesiunii. |
| Absența scrierilor HTTP în client | Clientul Axios conține numai apeluri `get`. | [`src/api.ts`](../src/api.ts): toate funcțiile exportate | `if rg -n 'client\.(post|put|patch|delete)' src/api.ts; then exit 1; else echo 'OK: no HTTP write calls in src/api.ts'; fi` | Verifică doar fișierul clientului din acest repository, nu capabilitățile serviciului extern. |
| Fixtures sintetice | Workspace-ul demo include ferme, câmpuri, sarcini, observații și activitate; identificatorii au prefixul `SYN-`. | [`src/fixtures.ts`](../src/fixtures.ts): `demoFarms`, `demoParcels`, `demoTasks`, `demoObservations`, `demoActivity`, `demoWorkspace` | `rg -n 'SYN-|demo(Farms|Parcels|Tasks|Observations|Activity|Workspace)' src/fixtures.ts` | Datele sunt fictive; nu sunt dovezi despre fermieri, GPS, cadastru sau alte date reale. |
| Comenzi de proiect | Scripturile declarate sunt `dev`, `build`, `test` și `lint`. | [`package.json`](../package.json): `scripts` | `npm run` | Enumeră scripturile disponibile; nu afirmă că au trecut fără rularea și raportarea lor separată. |
