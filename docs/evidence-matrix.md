# Matrice de dovezi

Comenzile se rulează din rădăcina repository-ului. Dovezile descriu strict codul clientului din acest repository; ele nu afirmă disponibilitatea sau capabilitățile unui serviciu extern.

| Capability | Evidence | Exact path/symbol | Verification command | Boundary |
| --- | --- | --- | --- | --- |
| Orchestrarea interfeței | Componenta principală gestionează dashboard-ul, filtrele, selecția, tab-urile și acțiunile locale. | [`src/App.tsx`](../src/App.tsx): `App`, `selectField`, `updateFilter`, `activeTab` | `rg -n 'function App|selectField|updateFilter|activeTab' src/App.tsx` | Dovedește orchestrarea în client, nu un workflow backend. |
| Alegerea sursei de date | Demo citește workspace-ul local; API mode activează query-ul `loadParcels` și nu înlocuiește eroarea sau răspunsul gol cu fixtures. | [`src/App.tsx`](../src/App.tsx): `dataMode`, `readDemoWorkspace`, `useQuery`, `fields` | `rg -n 'dataMode|readDemoWorkspace|useQuery|apiFields|Nu sunt afișate date demo' src/App.tsx` | Runtime-ul API conectează citirea câmpurilor. |
| Calea API compatibilă | Clientul Axios folosește `VITE_API_URL`; `loadParcels` execută `GET /parcels`, iar `loadFields` îl reutilizează. | [`src/api.ts`](../src/api.ts): `client`, `loadParcels`, `loadFields` | `rg -n "VITE_API_URL|client.get<Parcel\[\]>\('/parcels'\)|loadFields" src/api.ts` | Dovedește codul clientului, nu disponibilitatea continuă a API-ului. |
| Citiri API definite | Sunt exportate citiri pentru ferme, câmpuri, sarcini și observații. | [`src/api.ts`](../src/api.ts): `loadFarms`, `loadFields`, `loadTasks`, `loadObservations` | `rg -n 'function load(Farms|Fields|Tasks|Observations)' src/api.ts` | Existența lor nu înseamnă că toate sunt apelate de `App`. |
| Harta Leaflet, OSM și GeoJSON | `MapView` compune `MapContainer`, `TileLayer` cu URL OSM și stratul `GeoJSON`. | [`src/App.tsx`](../src/App.tsx): `MapView` | `rg -n 'MapContainer|TileLayer|tile.openstreetmap.org|<GeoJSON' src/App.tsx` | Dovedește configurația clientului, nu proveniența sau exactitatea geometriilor. |
| Conversia și exportul GeoJSON | Câmpurile devin un `FeatureCollection`; un câmp devine `Feature` pentru export. | [`src/App.tsx`](../src/App.tsx): `toFeatureCollection`, `fieldToGeoJSON`, `exportField` | `rg -n 'toFeatureCollection|fieldToGeoJSON|FeatureCollection|application/geo\+json' src/App.tsx` | Conversia folosește geometria furnizată; nu o validează ca GPS sau cadastrală. |
| Stare locală și resetare | `readDemoWorkspace` citește `localStorage`; efectul scrie numai în demo; `resetDemo` elimină cheia. | [`src/App.tsx`](../src/App.tsx): `LOCAL_KEY`, `readDemoWorkspace`, `resetDemo` | `rg -n 'LOCAL_KEY|localStorage\.(getItem|setItem|removeItem)|resetDemo' src/App.tsx` | Persistența este locală browserului, nu o bază de date sau sincronizare între clienți. |
| Mutații și audit locale | Sarcinile și observațiile modifică `localWorkspace` prin `setLocalWorkspace`; fiecare adaugă audit. | [`src/App.tsx`](../src/App.tsx): `addAudit`, `createTask`, `completeTask`, `addObservation`, `reviewObservation` | `rg -n 'addAudit|createTask|completeTask|addObservation|reviewObservation|setLocalWorkspace' src/App.tsx` | În API mode, aceste schimbări rămân în memoria sesiunii; nu sunt scrieri backend. |
| Fără scrieri HTTP în client | Toate apelurile Axios din client sunt `get`. | [`src/api.ts`](../src/api.ts): `client` și funcțiile exportate | `if rg -n 'client\.(post|put|patch|delete)' src/api.ts; then exit 1; else echo 'OK: no HTTP write calls in src/api.ts'; fi` | Verifică numai acest fișier client, nu serviciul extern. |
| Fixtures sintetice | Workspace-ul demo conține ferme, câmpuri, sarcini, observații și audit cu identificatori `SYN-*`. | [`src/fixtures.ts`](../src/fixtures.ts): `demoWorkspace`, `demoFarms`, `demoParcels`, `demoTasks`, `demoObservations`, `demoActivity` | `rg -n 'SYN-|demo(Farms|Parcels|Tasks|Observations|Activity|Workspace)' src/fixtures.ts` | Nu sunt dovezi despre persoane, ferme, coordonate sau registre reale. |
| Scripturi de proiect | Pachetul declară scripturi pentru dezvoltare, build, lint și teste. | [`package.json`](../package.json): `scripts` | `npm run` | Enumeră scripturile; rezultatul lor necesită rulare separată. |
